# 老年人居家安全常识

## 一、防骗防诈安全

### 1. 常见针对老人的骗局

- **冒充公检法**：自称警察/检察官，称老人涉嫌洗钱，要求转账到"安全账户"
  - 真相：公检法绝不会通过电话要求转账，更不存在"安全账户"
  - 应对：挂断电话，拨打110核实

- **冒充亲友求助**：自称孙子/儿子出车祸/被抓，急需打钱
  - 真相：声音可被AI伪造，骗徒利用老人关心家人的心理
  - 应对：挂断后用已知号码直接拨打亲属核实，不盲目转账

- **保健品推销**：免费体检/讲座/旅游，推销天价保健品
  - 真相：正规保健品不能替代药品，"包治百病"是虚假宣传
  - 应对：不参加来历不明的健康讲座，任何保健品购买前咨询医生

- **冒充社区工作人员**：自称社区干部上门，以补贴/登记为由骗取信息或钱财
  - 真相：社区工作人员有统一工牌和联系方式，可电话向社区核实
  - 应对：通过智能设备的摄像头查看门口来人，不认识的人不轻易开门

### 2. 门口来人应对原则
- **不认识的人不开门**：通过可视门铃或智能设备的摄像头确认来人身份
- **自称快递/维修的**：要求对方报出具体公司名和单号，先电话核实
- **自称检查水电气表的**：联系物业陪同，不在独处时开门
- **老人独自在家时**：门口有陌生人长时间逗留，立即通知物业或报警

### 3. 电话防骗三原则
- **不轻信**：任何要求转账的电话都是骗局
- **不透露**：不告诉对方银行卡号、密码、验证码
- **不转账**：挂断电话，告诉子女或拨打110

## 二、居家消防安全

### 1. 厨房安全
- 做饭时人不离灶，离开前关闭燃气阀门
- 锅起火时盖上锅盖，**切勿用水浇**
- 燃气灶附近不放易燃物（窗帘、纸巾、塑料袋）
- 定期检查燃气软管，老化龟裂及时更换（建议每2年换一次）

### 2. 用电安全
- 不在同一个插座接多个大功率电器（电磁炉、电暖器、微波炉）
- 电器不用时拔掉插头，尤其是电热毯、电暖器
- 发现插座发黑、电线破损立即停用并通知家属更换
- 手湿时不触碰开关和电器

### 3. 烟雾/燃气监测
- 厨房安装燃气泄漏报警器（天然气报警器安装高度距天花板30cm内）
- 卧室和客厅安装烟雾报警器
- 报警器每月测试一次（按测试键），每年更换电池

### 4. 火灾逃生
- 发生火灾时**不乘坐电梯**，走楼梯
- 用湿毛巾捂住口鼻，弯腰低姿前进
- 无法逃生时：关门堵缝（用湿毛巾塞门缝），到窗口挥动鲜艳衣物呼救
- 拨打119，说清地址和被困位置

## 三、居家环境安全

### 1. 防滑
- 卫生间、厨房地面保持干燥，有水立即擦干
- 淋浴区使用防滑垫
- 不穿拖鞋底已磨平的旧鞋
- 外出穿防滑鞋，雨天减少外出

### 2. 防磕碰
- 桌角、柜角贴防撞条
- 地面不堆放杂物，保持通道畅通
- 床头不放重物（防止地震或碰撞时坠落伤人）

### 3. 温度管理
- 夏季空调温度不低于26度，避免室内外温差过大导致血管收缩
- 冬季取暖注意通风，防止一氧化碳中毒（严禁在室内使用炭火取暖）
- 老人对温度感知迟钝，洗澡水温应调节在38-40度，防止烫伤

## 四、健康管理常识

### 1. 定期体检建议
| 检查项目 | 频率 | 说明 |
|---------|------|------|
| 血压 | 每周至少1次 | 高血压患者每天测量并记录 |
| 血糖 | 每3-6个月 | 糖尿病患者按医嘱自测 |
| 体检（全身体检） | 每年1次 | 包含心电图、血常规、肝肾功能、血脂 |
| 骨密度 | 每1-2年 | 尤其女性65岁以上、男性70岁以上 |
| 眼底检查 | 每年1次 | 糖尿病和高血压患者必查 |
| 肿瘤标志物 | 每年1次 | 结合家族史和年龄 |
| 口腔检查 | 每年1次 | 牙齿问题影响进食和营养 |

### 2. 营养建议
- **蛋白质**：每天每公斤体重1.0-1.2g蛋白质（如60kg老人每天60-72g），预防肌肉流失
- **钙**：每天1000-1200mg，乳制品+深绿叶蔬菜为主，不足时补充钙剂
- **维生素D**：每天800-1000IU，适当晒太阳（每天15-20分钟，避开正午）
- **膳食纤维**：每天25-30g，全谷物+蔬菜+水果，预防便秘
- **饮水量**：每天1500-1700ml（心肾功能不全者遵医嘱限量）
- **限盐**：每天不超过5g（约一啤酒瓶盖），高血压患者不超过3g

### 3. 运动建议
- 每周至少150分钟中等强度有氧运动（快走、太极、游泳）
- 每周2-3次力量训练（弹力带、自重训练）
- 运动前热身5-10分钟，运动后拉伸
- 运动时能正常说话但不能唱歌 = 中等强度
- 出现胸闷、头晕、关节剧痛立即停止运动

### 4. 睡眠管理
- 规律作息，固定时间上床和起床
- 卧室温度18-22度，保持安静黑暗
- 午睡不超过30分钟，下午3点后不睡
- 如厕次数增多影响睡眠时，睡前2小时减少饮水
- 长期失眠（超过1个月）应就医，不要长期依赖安眠药

## 五、心理健康

### 1. 常见心理问题
- **孤独感**：独居老人、丧偶老人高发
- **焦虑**：对健康的过度担忧、对子女安全的牵挂
- **抑郁**：表现为兴趣下降、食欲减退、睡眠紊乱、反复诉说身体不适
- **认知衰退**：短期记忆下降、迷路、性格改变可能是阿尔茨海默病早期信号

### 2. 应对建议
- 保持社交：每天与家人通话或视频，参加社区活动
- 培养爱好：书法、园艺、棋牌、散步
- 规律运动：运动是天然的抑郁焦虑缓解剂
- 家属定期探望或视频通话，关注老人情绪变化
- 发现持续情绪低落超过2周，建议就医（老年抑郁常被忽视）
- 发现记忆障碍、性格改变、行为异常尽早就诊神经内科

## 六、紧急情况处理

### 1. 拨打120时的要点
- 说清地址：XX市XX区XX路XX号XX室
- 说清症状：意识是否清醒、有无胸痛、有无呼吸困难
- 说清病史：有无心脏病、糖尿病、正在服用的药物
- 留人接应：派人到路口引导救护车
- 不要先挂电话：等接线员说可以挂断

### 2. 胸痛（疑似心梗）
- 立即停止活动，就地坐下或半卧位
- 拨打120，不要自行驾车去医院
- 含服硝酸甘油（舌下，有冠心病史者随身携带）
- 服用阿司匹林（300mg嚼碎服下，既往无禁忌者）
- 保持安静，减少搬动
- **不要**用力咳嗽、拍打手臂等"自救偏方"

### 3. 中风（脑卒中）
识别口诀"120"：
- **1**看一张脸：面部是否不对称（嘴角歪斜）
- **2**查两只胳膊：一侧胳膊是否无力下垂
- **0**听语言：说话是否含糊不清
- 出现任何一项，立即拨打120
- 记录症状出现时间（发病时间决定能否溶栓，黄金时间4.5小时）
- 让老人平卧，头偏向一侧（防呕吐误吸）
- 不要喂水喂药（吞咽障碍时可能呛入气管）
