# 老人用药安全指南

## 一、常见药物分类及服用注意事项

### 1. 降压药
- **常用药物**：氨氯地平（络活喜）、缬沙坦（代文）、美托洛尔（倍他乐克）
- **服用时间**：多数降压药建议早晨空腹或餐前服用，具体遵医嘱
- **注意事项**：
  - 不可自行停药或增减剂量，即使血压已正常
  - 服药后变换体位要缓慢（如起床先坐1分钟再站起），防止体位性低血压跌倒
  - 定期监测血压并记录，复诊时带给医生参考
- **漏服处理**：发现漏服时，如果距离下次服药超过4小时，可补服；不足4小时则跳过，切勿双倍服用

### 2. 降糖药
- **常用药物**：二甲双胍（格华止）、格列美脲（亚莫利）、胰岛素
- **服用时间**：
  - 二甲双胍：餐中或餐后服用，减少胃肠道刺激
  - 格列美脲：早餐前30分钟服用
  - 胰岛素：按医嘱，通常餐前15-30分钟注射
- **注意事项**：
  - 服药期间严禁空腹运动，防止低血糖
  - 随身携带糖果或饼干，出现心慌、手抖、出冷汗时立即食用
  - 定期监测血糖，糖化血红蛋白每3个月查一次

### 3. 抗凝药/抗血小板药
- **常用药物**：阿司匹林、华法林、氯吡格雷（波立维）
- **服用时间**：阿司匹林肠溶片建议晚餐后服用；华法林固定时间服用
- **注意事项**：
  - 服药期间注意出血倾向：牙龈出血、皮肤淤斑、大便发黑
  - 华法林患者需定期查INR（国际标准化比值），控制在2.0-3.0
  - 避免突然大量食用富含维生素K的食物（菠菜、西兰花等）

### 4. 镇静催眠药
- **常用药物**：艾司唑仑（舒乐安定）、右佐匹克隆、唑吡坦（思诺思）
- **服用时间**：睡前15-30分钟服用
- **注意事项**：
  - 服药后必须立即上床，不要再走动，防止跌倒
  - 长期服用易产生依赖性，不可自行加量
  - 停药需逐步减量，突然停药可能出现反跳性失眠

### 5. 骨质疏松药
- **常用药物**：阿仑膦酸钠（福善美）、钙尔奇D、骨化三醇
- **服用时间**：
  - 阿仑膦酸钠：清晨空腹，用满杯白开水送服，服药后保持直立至少30分钟
  - 钙剂：餐后服用，与维生素D同服促进吸收
- **注意事项**：
  - 阿仑膦酸钠必须空腹服用，不可与牛奶/钙剂同服
  - 服药后30分钟内不躺下，防止食管刺激

## 二、用药安全管理原则

### 1. 服药记录
- 每次服药后及时打卡记录（可使用智能设备的服药提醒功能）
- 记录内容包括：药名、剂量、服药时间、是否出现不适
- 每周整理服药情况，复诊时带给医生

### 2. 药物储存
- 药品分类存放，内服药与外用药分开
- 避光、避热、避潮保存，浴室不适合放药
- 定期检查有效期，过期药不可继续服用
- 高危药品（如华法林、胰岛素）单独存放，标识清楚

### 3. 多重用药管理
- 老年人同时服用5种以上药物时，药物相互作用风险显著增加
- 每3-6个月请医生做一次"药物重整"（Medication Reconciliation）
- 就诊时带所有正在服用的药品（包括保健品）给医生看
- 新增药物时主动询问医生：是否与现有药物冲突

### 4. 漏服与误服处理
- 发现漏服时按各药物规定处理（见上文各分类）
- 误服或过量服用时，立即携带药品包装前往医院急诊
- 出现皮疹、呼吸困难、面部肿胀等过敏反应时立即就医

## 三、给家属的建议

- 定期帮助老人整理药盒（建议使用分格药盒，按早/中/晚/睡前分装）
- 关注老人是否按时服药，留意有无囤药、拒药行为
- 老人认知功能下降时，由家属协助管理药品，避免自行出错
- 保留药品说明书，方便随时查阅用法用量和禁忌
