# 智能设备使用指南（银发经济版）

## 一、设备能做什么

本设备是一台带摄像头、麦克风、喇叭和屏幕的智能语音助手，专为老年人设计。以下功能无需手机或电脑，直接对设备说话即可使用。

## 二、语音指令清单

### 1. 服药管理
| 想做什么 | 对设备说 |
|---------|---------|
| 记录已服药 | "我吃过降压药了" / "我刚吃了钙片" |
| 查询今天服药情况 | "今天药吃了没" / "我吃药了吗" |
| 设置服药提醒 | "提醒我每天早上8点吃降压药" / "30分钟后提醒我吃药" |

### 2. 找东西
| 想做什么 | 对设备说 |
|---------|---------|
| 找眼镜 | "帮我找找眼镜" |
| 找钥匙 | "我的钥匙在哪" |
| 找手机 | "帮我找手机" |

设备会拍照并用AI分析画面，告诉你东西在什么位置。

### 3. 门口安全
| 想做什么 | 对设备说 |
|---------|---------|
| 查看门口是谁 | "看看门口是谁" / "门口有人吗" |

设备会拍照并描述来人的特征（穿着、人数），帮助判断是否应该开门。

### 4. 天气查询
| 想做什么 | 对设备说 |
|---------|---------|
| 查今天天气 | "今天天气怎么样" / "外面冷不冷" |
| 查指定城市 | "北京天气怎么样" |

不带城市名时设备会自动定位你所在的城市。

### 5. 日程提醒
| 想做什么 | 对设备说 |
|---------|---------|
| 添加日程 | "下午3点提醒我去医院" / "周二提醒我交水费" |
| 查看日程 | "我有什么提醒" |

到时间设备会连响三声提示音并显示在屏幕上。

### 6. 紧急联系人
| 想做什么 | 对设备说 |
|---------|---------|
| 添加联系人 | "存一下我儿子的电话，13800138000" |
| 查看联系人 | "我的紧急联系人有哪些" |

### 7. 家属留言
| 想做什么 | 对设备说 |
|---------|---------|
| 听留言 | "有什么留言吗" / "我儿子留言说了什么" |

## 三、SOS紧急按钮使用方法

### 按键位置
设备侧面有一个物理按钮（GPIO3引脚，已接线）。

### 使用方法
- **长按3秒**触发紧急告警
- 短按或长按不足3秒不会触发（防止误按）

### 触发后设备会
1. 屏幕显示"紧急求助"和紧急联系人信息
2. 连续播放告警提示音（三声）
3. 向家属端推送告警通知

### 什么时候用SOS
- 感到胸闷、呼吸困难、剧烈头痛时
- 跌倒后无法站起时
- 独自在家感到不安全时
- **慌乱中无法说话时——按住3秒就够，不需要喊**

## 四、自动功能（无需说话，设备自己运行）

以下功能在后台自动运行，老人不需要做任何操作：

| 功能 | 说明 |
|------|------|
| 跌倒检测 | 定时拍照分析，判断是否跌倒，检测到自动告警通知家属 |
| 久坐提醒 | 检测长时间未活动，到时提醒"起来走走" |
| 离床告警 | 夜间检测长时间离床未归，自动告警 |
| 日程到点播报 | 到了设定时间自动连响三声提示音 |

## 五、设备无法做的事

诚实告知，以下功能设备目前无法做到：
- **拨打电话**：设备不能代替手机拨打120或家属电话，紧急情况请用手机或座机
- **移动跟随**：设备固定放置，摄像头只能拍到一个方向
- **24小时录像**：只在需要时拍照分析，不持续录像
- **完全代替护理**：设备是辅助提醒工具，不能代替人工照护
