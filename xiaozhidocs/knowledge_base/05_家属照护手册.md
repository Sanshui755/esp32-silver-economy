# 家属照护手册

本手册面向使用智能语音助手的老人家属，帮助理解设备功能并配合使用。

## 一、你的角色

智能设备是辅助工具，不能代替家属照护。你的核心职责是：

1. **定期查看设备传回的信息**：服药记录、告警通知
2. **管理云端工具（可选）**：在家时启动电脑端服务，查看周报告、给老人留言
3. **维护药品和设备**：定期整理药盒、检查设备运行状态
4. **关注老人情绪**：设备无法感知老人心理状态，需要你保持沟通

## 二、设备端功能（24小时在线，不依赖电脑）

以下功能由设备本身完成，你的电脑开关机不影响它们：

| 功能 | 你能做什么 |
|------|-----------|
| 服药打卡 | 每天查看老人是否按时服药（问设备"今天药吃了没"） |
| 跌倒检测 | 收到跌倒告警时第一时间联系老人或前往查看 |
| SOS按键 | 收到SOS告警立即处理（打电话/前往/拨打120） |
| 日程提醒 | 帮老人设置重要日程（如"周三下午复诊"），设备到点自动提醒 |
| 紧急联系人 | 确保联系人信息准确、电话能打通 |
| 天气查询 | 老人可自行查询，你无需每天提醒穿衣 |

## 三、云端工具（你的电脑在线时可用）

以下工具需要你的电脑运行 `mcp_pipe.py` 才可用：

### 1. 服药周报告
- 老人问"我这周吃药怎么样"时，AI 调用你电脑上的 `family_service.py`
- 读取 `medication_log.json` 中的打卡记录，生成依从率报告
- 目前数据为示例数据，后续可接入设备 NVS 同步的真实数据

### 2. 家属留言
- 家属在电脑端调用 `add_family_message` 写留言
- 老人对设备说"有什么留言吗"即可听到
- 适合留"明天降温多穿点""周三下午陪你去医院"这类提醒

### 3. 如何启动云端工具
```powershell
cd F:\All_Code\ESP32\mcp-calculator
python mcp_pipe.py family_service.py
```
看到 `Successfully connected to WebSocket server` 即在线。

### 4. 如何手动写留言
编辑 `family_messages.json`，按现有格式追加一条即可（下次老人询问时生效）。

## 四、日常照护建议

### 每日
- [ ] 查看老人服药是否打卡（可远程问设备）
- [ ] 晚间通话确认老人状态
- [ ] 检查有无未处理的告警

### 每周
- [ ] 整理药盒（按早/中/晚/睡前分装一周药品）
- [ ] 查看服药周报告（电脑在线时）
- [ ] 给老人留1-2条语音/文字留言
- [ ] 检查设备摄像头是否被遮挡、电源是否稳定

### 每月
- [ ] 检查药品有效期，补充即将过期的药
- [ ] 协助老人测量血压、血糖并记录
- [ ] 检查居家环境安全隐患（地面、照明、扶手）
- [ ] 陪同复诊，带齐服药记录给医生参考

### 每季度
- [ ] 评估老人认知功能（有无记忆下降、性格改变）
- [ ] 评估跌倒风险（平衡测试、步态观察）
- [ ] 更新紧急联系人信息

## 五、告警处理流程

### 跌倒告警
1. 立即联系老人确认情况
2. 无法联系上 → 前往查看或请邻居/物业帮忙
3. 老人无法站起或主诉疼痛 → 拨打120
4. 事后了解跌倒原因，排查环境隐患

### SOS告警
1. 立即联系老人
2. 无法联系上 → 前往查看
3. 老人身体不适 → 拨打120
4. 老人惊吓或恐慌 → 安抚情绪，了解触发原因

### 离床告警（夜间）
1. 电话确认老人是否在卫生间或客厅
2. 确认老人无跌倒、无不适
3. 老人已回床 → 正常，可继续睡
4. 老人未回床且无法联系 → 前往查看

## 六、数据说明

| 数据类型 | 存储位置 | 保留时间 | 谁能看 |
|---------|---------|---------|--------|
| 服药打卡 | 设备 NVS | 持久 | 设备端工具查询、AI 播报 |
| 日程提醒 | 设备 NVS | 打卡后清除 | 设备端工具查询 |
| 紧急联系人 | 设备 NVS | 持久 | SOS 触发时显示 |
| 服药周报告 | 电脑 JSON | 直到你删除 | 云端工具查询 |
| 家属留言 | 电脑 JSON | 直到你删除 | 老人通过设备听取 |

**注意**：设备 NVS 数据在 `idf.py erase-flash` 后会清空。云端工具数据在电脑上，不受设备操作影响。
